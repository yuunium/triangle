# SANKAKU

**正七角形、つくれる？** 7つの点でぴったりを目指す、目測のブラウザーゲームです。三角形〜六角形での練習と、八角形の別モードもあります。

## 遊び方

1. トップの「正七角形に挑戦」からメインのお題へ。「練習・別モードを選ぶ」を開くと、三角形〜六角形の練習と八角形の別のお題を選べます。ゲーム開始後は右上から変更できます。
2. 盤面をクリック／タップして、A〜Hの順に必要な数の点を配置。外周をたどる順に置いてください。
3. 点をドラッグして、納得いくまで調整。
4. 「採点する」で一致度を表示。この回の点と結果は確定し、以後ドラッグ・キーボードでも編集できません。
5. 採点後は一番近い正多角形を自動で重ねて答え合わせ（チェックで非表示にできます）。「もう一度つくる」は形を聞き直さず同じ形で再開し、右上から別の形にも変更できます。

マウス・タッチ・キーボード対応。盤面にTabでフォーカスし、矢印でカーソルを動かしてEnterで点を配置できます。配置済みの点もTabで選び、矢印で移動できます。Shift＋矢印は微調整です。

## 結果画像とXへの投稿

採点後、「結果を画像でシェア」で確定した図形・一致度を含む1200×675のPNGを共有できます。ファイル共有対応の端末ではOSの共有メニューが開くので、共有先からXなどを選びます。端末や共有先によって対応状況は異なります。

「画像保存・Xに投稿」からは、結果画像のプレビュー・保存・Xの投稿画面を利用できます。**画像を保存し、Xの投稿画面で添付してください。** 本文・一致度・その形へのリンクは入力済みで開きます。Web Intentへ画像を自動添付したと誤表示しません。XアカウントのAPI認証・メディアのサーバーアップロード・自動投稿は行いません。

画像はブラウザー内で生成し、外部へ自動送信しません。ネイティブ共有をキャンセルしても投稿やダウンロードを勝手に続けません。メインの七角形はルートURL、ほかの形は`?sides=3`や`?sides=8`などで形を指定して共有します。他モードの共有リンクでは、その形を始める専用の入口も表示します。

## ローカル開発

Node.js 22以上を使用します。

```sh
npm ci
npm run dev
```

```sh
npm test          # 採点・多角形フィット・共有URLのテスト
npm run build    # 静的ファイルを dist/client に出力
npm run preview  # 本番ビルドのプレビュー
```

React + Vite。サーバーや環境変数、外部APIへの接続は不要です。アイコンと日本語フォントもビルドに同梱されます。

## GitHub Pages

`.github/workflows/pages.yml` が、mainへのpush時にテスト・ビルド・デプロイを実行します。

GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。その後mainにpushするか、Actionsの **Deploy GitHub Pages → Run workflow** を実行します。

このリポジトリの公開先は `https://yuunium.github.io/triangle/` です。公開の成否はActionsの実行結果で確認できます。

Viteの`base: './'`により、リポジトリ名の付いたサブパスでもアセットを読み込めます。GitHub Pagesに必要なのは`dist/client`の静的ファイルだけです。テンプレート由来の`worker/`と`.openai/`は、将来別のホスティングへ移す場合に備えて残しています。

## 採点

nを角の数、面積をAとして、以下を計算します。

```text
一致度 [%] = 100 × 4tan(π/n) × A / 各辺の長さの2乗の合計
```

位置・大きさ・回転・鏡映には依存しません。選んだ正多角形は100%、一直線または全点が重なる場合は0%。辺が交差している場合も0%です。三角形では従来の`4√3 × A / (a²+b²+c²)`と同じで、直角二等辺三角形は約86.60%です。正方形モードの2:1の長方形は80%になります。

表示は小数点以下2桁。完全一致と区別するため、100%未満の値が丸めで100.00%になる場合は99.99%と表示します。浮動小数点誤差の許容範囲はスコアで1e-10です。

採点後の点線は、重心を保った最小二乗の正多角形です。これはずれを見比べるためのガイドで、採点式そのものとは別です。辺が交差した図形や一直線の図形ではガイドを無効にします。

## 将来のランキング

採点はReactに依存しない`src/geometry.mjs`にまとめています。Cloudflare Workersなどでも同じモジュールを利用できます。`SCORING_VERSION`は`regular-polygon-q-v1`です。既存の`evaluateTriangle`と`fitEquilateral`も互換用に残しています。

追加時の想定構成は **GitHub Pages（ゲーム）→ Cloudflare Worker（ランキングAPI）→ D1（記録）**。送信データは角の数・全頂点の座標・採点バージョン・表示名を基本とし、サーバーで一致度を再計算して保存します。角の数ごとにランキングを分けられます。現在はAPI・データベース・ランキング機能を接続していません。

## デザイン

選択した白地とオレンジの案に沿って、盤面を主役にした構成です。[Emil Kowalskiのデザイン指針](https://github.com/emilkowalski/skills)を参考に、直接追従するドラッグ、短い押下フィードバック、目的のある結果表示、reduced-motion対応を実装しています。
